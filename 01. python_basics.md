## Python basics

This quick reference covers core Python fundamentals with short, runnable examples and notes.

---

## Variables and datatypes

Python variables are dynamically typed. Use `type()` or `isinstance()` to inspect types.

- Integers and floats

```python
x = 10       # int
pi = 3.1415  # float
print(type(x), type(pi))
```

- Strings

```python
s = "hello"
print(s[0], len(s))
```

- Booleans and None

```python
flag = True
nothing = None
print(bool(0), bool([]), nothing is None)
```

- Containers

Lists (mutable), tuples (immutable), sets (unique unordered), dictionaries (key->value)

```python
lst = [1, 2, 3]
tpl = (1, 2, 3)
st = {1, 2, 3}
d = {'a': 1, 'b': 2}

# common operations
lst.append(4)
print(tpl[0], 2 in st, d['a'])
```

Notes:
- Python variables reference objects; assignment binds a name to an object.
- Use `is` for identity checks (same object), `==` for equality.

## Conditions (if / elif / else)

```python
x = 5
if x < 0:
    print('negative')
elif x == 0:
    print('zero')
else:
    print('positive')
```

Comparisons: `==`, `!=`, `<`, `<=`, `>`, `>=`.
Logical operators: `and`, `or`, `not`.

Truthiness: empty containers, `0`, and `None` are considered False in boolean contexts.

```python
if [] or 0:
    print('won\'t run')
else:
    print('falsey values')
```

## Loops and iterators

### for loops

Python's `for` iterates over any iterable (lists, tuples, strings, generators, etc.).

```python
for i in [10, 20, 30]:
    print(i)
```

Useful helpers:

- `range(stop)` / `range(start, stop[, step])` — produces an integer sequence.

```python
for i in range(3):
    print(i)  # 0, 1, 2
```

- `enumerate(iterable, start=0)` — yields (index, value) pairs.

```python
for idx, val in enumerate(['a', 'b']):
    print(idx, val)
```

- `zip(*iterables)` — iterate parallel over multiple iterables, stops at shortest.

```python
for a, b in zip([1,2], ['x','y']):
    print(a, b)
```

### while loops

```python
n = 3
while n > 0:
    print(n)
    n -= 1
```

Break/continue/else:

```python
for i in range(5):
    if i == 3:
        break
else:
    # this runs only if loop completed without break
    print('completed')
```

### What is an iterator?

An iterator is an object that implements the iterator protocol: it has an `__iter__()` method returning itself and a `__next__()` method that returns the next item or raises `StopIteration` when done. Many built-ins (lists, dicts, files, range) are iterable; calling `iter()` on them returns an iterator.

Example using `iter()` and `next()`:

```python
lst = [10, 20]
it = iter(lst)
print(next(it))  # 10
print(next(it))  # 20
# next(it) now would raise StopIteration
```

Generators (functions using `yield`) produce iterators lazily and are memory-efficient for large or infinite sequences.

```python
def counter(n):
    i = 0
    while i < n:
        yield i
        i += 1

for x in counter(3):
    print(x)
```

## Functions: definition and parameter types

Define functions with `def`. Use a docstring for brief documentation.

```python
def add(a, b):
    """Return a + b"""
    return a + b

print(add(2, 3))
```

Parameter types:
- Positional-only (Python 3.8+ marker `/`) — rarely used in examples.
- Positional-or-keyword — the default.
- Keyword-only arguments (use `*` to mark the end of positional args).
- Default values provide optional args.

```python
def greet(name, msg='Hello'):
    print(msg, name)

greet('Alice')
greet('Bob', msg='Hi')  # keyword argument
```

### Variable-parameter functions: *args and **kwargs

`*args` captures extra positional arguments as a tuple.
`**kwargs` captures extra keyword arguments as a dict.

```python
def f(a, *args, **kwargs):
    print('a =', a)
    print('*args =', args)
    print('**kwargs =', kwargs)

f(1, 2, 3, x=10, y=20)
# a = 1
# *args = (2, 3)
# **kwargs = {'x': 10, 'y': 20}
```

Order in signature: positional-or-keyword params, `*args`, keyword-only params, `**kwargs`.

Why the difference?
- `*args` is used when you want a function to accept a variable number of positional arguments.
- `**kwargs` is used to accept arbitrary keyword arguments.

Unpacking when calling functions:

```python
nums = (1, 2)
params = {'sep': ','}
print(*nums)              # expands positional arguments
print('a', 'b', **params) # expands keyword args
```

Common pitfalls:
- Do not use mutable default arguments (like `def f(x, lst=[])`) — they persist across calls.

## Modules and imports

A module is any `.py` file. Put related functions/classes in a module and import them.

Example: create a file `mymath.py`:

```python
# mymath.py

def add(a, b):
    return a + b

PI = 3.1415
```

Import styles from another file:

```python
import mymath
print(mymath.add(1, 2))

from mymath import add, PI
print(add(3, 4))

from mymath import *  # not recommended in libraries (pollutes namespace)

import mymath as mm  # aliasing
print(mm.PI)
```

Packages: directories with an `__init__.py` file are packages. Use relative imports within packages (e.g. `from . import sibling` or `from ..pkg import something`).

Notes on module search:
- Python searches `sys.path` (current dir, environment paths, site-packages).
- For quick tests, run a script from the package root or set `PYTHONPATH`.

## Quick reference / cheatsheet

- Create an iterator: `it = iter(some_iterable)` and fetch with `next(it)`.
- Loop helpers: `range()`, `enumerate()`, `zip()`.
- Function signatures: `def f(a, b=1, *args, kw_only, **kwargs):` (use `*` to force keyword-only args).
- Import: `import module`, `from module import name`, `import module as alias`.
